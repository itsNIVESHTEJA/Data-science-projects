📌 Project Title & Introduction

ECG Classification Using Deep Learning is a system developed to automatically analyze electrocardiogram (ECG) signals and classify them into medical categories. This project leverages modern Convolutional Neural Networks (CNNs) to identify cardiac abnormalities from ECG images, assisting healthcare professionals in early detection of heart-related issues.

🎯 Purpose

ECG classification is vital in cardiology as it helps in the early detection of life-threatening conditions such as myocardial infarction or arrhythmia. By automating this process:

  • Doctors receive faster diagnostic support.
  • Patients benefit from timely medical intervention.
  • Hospitals reduce manual workload and increase efficiency.

📊 Dataset Information

The dataset used in this project consists of ECG images collected from medical repositories and open-source healthcare datasets. It includes four main categories with thousands of samples:

  • Myocardial Infarction
  • History of MI
  • Abnormal Heartbeat
  • Normal

🤖 Model Information

A Convolutional Neural Network (CNN) was trained on the dataset to achieve high accuracy in classification. Key details include:

  • Architecture: Convolutional Neural Network (CNN)
  • Input Size: 128x128 ECG images
  • Epochs: 20–30 (depending on dataset size)
  • Accuracy: ~90% on validation data

📚 Classes Explanation

  • Myocardial Infarction: Indicates an active or past heart attack event.
  • History of MI: Suggests previous occurrence of myocardial infarction.
  • Abnormal Heartbeat: Captures irregularities in ECG signals.
  • Normal: Represents a healthy cardiac rhythm.

🛠 How to Use

  1. Login or Register on the ECG Portal.
  2. Navigate to the Classification page.
  3. Upload an ECG image (PNG/JPG).
  4. Click on Predict to let the model analyze your ECG.
  5. View your classification result instantly.
