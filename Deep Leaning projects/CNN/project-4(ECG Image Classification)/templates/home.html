Welcome to the ECG Portal

This project is designed to provide an advanced platform for the classification and monitoring of ECG (Electrocardiogram) signals using deep learning. It allows both administrators and users to interact with the system efficiently, analyze heart conditions, and maintain a secure login-based workflow. Admins can monitor login activity, approve new users, and oversee the system, while users can perform ECG classification, view descriptions of conditions, and access detailed results.

Built using Flask, Keras, and Excel-based storage, this system integrates a CNN model to classify ECG images into categories such as Myocardial Infarction, History of MI, Abnormal Heartbeat, and Normal. It emphasizes usability with a clean and responsive Tailwind CSS interface.
